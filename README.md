# Karthik S R — Salesforce Business Analyst portfolio

Modern, accessible, mobile-responsive, static GitHub Pages portfolio.

## Publish

The redesign lives on branch \`portfolio-redesign-ba-2026\`. Review the branch, then merge its pull request into \`main\`. GitHub Pages should serve the new \`index.html\` automatically if Pages is configured to deploy from \`main\` / root.

## Files

- \`index.html\`: semantic sections, experience, case studies, credentials, contact
- \`styles.css\`: responsive visual system
- \`script.js\`: mobile navigation, certificate filters, PDF preview
- \`favicon.svg\`: site icon
- existing PDFs are reused without changes.

## Customize before going live

- Confirm work dates, exact role titles, and project descriptions.
- Verify original PDFs and course providers. The portfolio does **not** claim these are official Salesforce vendor certifications.
- Replace \`resume.pdf\` with an updated résumé if it still lists an older role.
- Verify the contact form works and that its Basin account is yours.
- Add quantified outcomes only when you can substantiate them.
- Generalized case studies should not disclose employer-sensitive information.

This site requires no build tools or dependencies. Open \`index.html\` in any modern browser to preview.
